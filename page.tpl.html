Web crawler /[•]\

A wireframe spider that walks across the links of any web page, grabs them and tears pieces off. Inspired by a video by @rybinfx.

Install as a bookmarklet

  1. Tap Copy the bookmarklet.
  2. Bookmark any page (Chrome Android: menu ⋮ then the star).
  3. Edit that bookmark: name it spider and paste the code as its URL.
  4. On any page (Wikipedia works great), type spider in the address bar and pick the bookmark from the suggestions. On desktop, just click the bookmark. Run it again, or press Esc, to stop.
